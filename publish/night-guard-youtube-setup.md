# The Night Guard: YouTube channel and Short 1 setup

Paste each block into the matching field in YouTube Studio.

The series gets its own channel. Your science channel ("Chris Ouimet", "Weird questions, real science") has a different audience, and mixing the two would confuse both the viewers and YouTube's recommendations. A second channel can sit on the same Google account: YouTube → your picture → Settings → **Create a new channel**.

## Channel

**Name** (Studio → Customization → Profile → Name):

```
The Night Guard
```

**Handle** (same page, Handle). Try these in order and keep the first one Studio says is free:

```
@TheNightGuardStories
```
Then `@NightGuardStories`, then `@TheNightGuardTV`.

**Description** (same page, Description; 573 of 1,000 characters):

```
I'm Danny, the night guard at Maplecrest Mall. I carry forty-two keys, one for every store. The night the dead came, I locked myself inside, and my seven-year-old daughter was a mile and a half away, across the highway.

The Night Guard is an animated zombie survival story, told one chapter at a time. Every Short picks up where the last one left off, so start at Part 1 and follow along. Full chapters are on the way.

New parts every day. Subscribe so you don't miss what happens next.

The old guard told me never to use the last key. I'm about to find out why.
```

**Keywords** (Studio → Settings → Channel → Basic info → Keywords):

```
the night guard, zombie story, zombie apocalypse, zombie animation, animated story, zombie survival, survival story, horror story, scary stories, storytime, zombie shorts, mall zombie, apocalypse story, stick figure animation

**Tags** (Show more → Tags; about 260 of 500 characters):

```
zombie story, zombie apocalypse, zombie shorts, zombie animation, animated story, survival story, zombie survival, scary story, horror story, storytime, the night guard, night guard, mall security guard, zombie mall, stick figure animation, apocalypse

**Playlist:** create a new playlist with this name:

```
The Night Guard
```
and this description:
```
The whole story, in order. Start with Part 1.
```

**Settings to pick:**

| Field | Choose |
|---|---|
| Audience | No, it's not made for kids |
| Age restriction | No, don't restrict my video to viewers over 18 |
| Paid promotion | Leave unticked |
| Altered or synthetic content | No. It's clearly animated fiction, and YouTube only asks for this label on realistic-looking content. |
| Category | Film & Animation |
| Video language, and title and description language | English |
| Caption certification | None. The captions are already in the video. |
| License | Standard YouTube License |
| Allow embedding | On |
| Publish to subscriptions feed and notify subscribers | On |
| Shorts remixing | Allow video and audio remixing |
| Comments | On, with moderation set to Basic |
| Show how many viewers like this video | On |
| Visibility | Public. Or schedule it, and post each part at the same time every day. |

**Thumbnail:** in the YouTube app, tap **Thumbnail** while uploading and choose the very first frame: the zombie at the gate. Shorts uploaded from a computer can't use a custom thumbnail in the Shorts feed.

**Pinned comment.** Post it once the Short is live, then tap ⋮ → Pin:

```
What would you do if your best friend was on the other side of that gate? 👇 Part 2 drops tomorrow.
```

**After Part 2 is up:** edit Short 1 → **Related video** → choose Part 2, so a link to the next part shows under the Short.
